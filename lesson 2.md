# lesson 2

## 这是什么？ What is this?

In lesson 1, we learned the tones and met a few monkeys. Now let's give those monkeys something to say.

By the end of this lesson, you can name an animal, ask what it is, and correct someone who thinks every animal is a monkey.

## Tone warm-up

Read these words aloud. Can you remember the tone before looking at the pinyin?

| 中文 Chinese | 拼音 pinyin | 英文 English |
| ------------ | ----------- | ------------ |
| 黑 | hēi | black |
| 猴 | hóu | monkey |
| 小 | xiǎo | small |
| 大 | dà | big |

A small clarification from lesson 1: tones use your own comfortable pitch range, not a fixed musical note. The neutral tone is usually shorter and lighter than a full tone, and its pitch depends on what comes before it. Dictionaries can show neutral-tone pronunciations too, as in 猴子 hóuzi.

## Vocabulary

| 中文 Chinese | 拼音 pinyin | 英文 English |
| ------------ | ----------- | ------------ |
| 这 | zhè | this |
| 那 | nà | that |
| 是 | shì | to be: am, is, are |
| 什么 | shénme | what |
| 吗 | ma | particle for yes/no questions |
| 不 | bù | not; no |
| 猴子 | hóuzi | monkey |
| 鸟 | niǎo | bird |

The second syllables in 什么 shénme and 猴子 hóuzi are neutral-tone syllables. Say them lightly.

## This is a monkey

Let's start with a simple sentence:

**这是猴子。**

*Zhè shì hóuzi.*

This is a monkey.

| 这 | 是 | 猴子 |
| :--: | :--: | :--: |
| this | is | monkey |

The pattern is **这 + 是 + noun**. To talk about something farther away, replace 这 with 那:

* 这是鸟。 Zhè shì niǎo. — This is a bird.
* 那是猴子。 Nà shì hóuzi. — That is a monkey.
* 那是大猩猩。 Nà shì dà xīngxing. — That is a gorilla.

English needs an article in “a monkey.” Chinese does not need an equivalent article in this sentence.

## What is this?

Replace the animal with 什么:

**这是什么？**

*Zhè shì shénme?*

What is this?

Notice that 什么 stays in the same place as the thing you want to identify. You don't need to move it to the beginning as English does.

> **A:** 这是什么？ Zhè shì shénme? — What is this?
>
> **B:** 这是猴子。 Zhè shì hóuzi. — This is a monkey.

Try pointing to something farther away and asking **那是什么？ Nà shì shénme?** — What is that?

## Is this a monkey?

If you already have a guess, add 吗 to the end of the statement:

* 这是猴子。 Zhè shì hóuzi. — This is a monkey.
* 这是猴子吗？ Zhè shì hóuzi ma? — Is this a monkey?

吗 is a light, neutral-tone syllable. Keep the tones of the other words; you don't need to turn every syllable into a rising English question.

To answer this question, use:

| 中文 Chinese | 拼音 pinyin | 英文 English |
| ------------ | ----------- | ------------ |
| 是。 | Shì. | Yes. / It is. |
| 不是。 | Bú shì. | No. / It isn't. |

**Pronunciation trick:** 不 is normally bù, but before another fourth-tone syllable it becomes bú. So 不是 is pronounced **bú shì**.

什么 already makes “这是什么？” a question. Don't add 吗 to that question.

## That is not a monkey

Put 不 before 是 to correct a guess:

**这不是猴子。这是鸟。**

*Zhè bú shì hóuzi. Zhè shì niǎo.*

This isn't a monkey. This is a bird.

Even a monkey can make a mistake. A bird friend might have something to say about this one.

## Practice

### 1. Fill in the blanks

1. This is a monkey. → 这___猴子。
2. What is this? → 这是___？
3. Is this a bird? → 这是鸟___？
4. This isn't a gorilla. → 这___是大猩猩。

### 2. Guess the animal

Use pictures of a monkey, bird, gorilla, and chimpanzee. Take turns asking and answering. Sometimes make a deliberately wrong guess.

> **A:** 这是猴子吗？ Zhè shì hóuzi ma? — Is this a monkey?
>
> **B:** 不是。这是鸟。 Bú shì. Zhè shì niǎo. — No. This is a bird.
>
> **A:** 那是什么？ Nà shì shénme? — What is that?
>
> **B:** 那是黑猩猩。 Nà shì hēi xīngxing. — That is a chimpanzee.

### 3. Try without pinyin

Read these aloud and explain what they mean:

* 这是什么？
* 这是猴子吗？
* 不是。这是大猩猩。

**Answers to exercise 1:** 1. 是  2. 什么  3. 吗  4. 不

## Pokemon of the day: 火暴猴 Primeape

Remember 猴怪 Mankey from lesson 1? Meet its evolution:

| 火 | 暴 | 猴 |
| :--: | :--: | :--: |
| huǒ | bào | hóu |
| fire | fierce; violent | monkey |

火 and 暴 are bonus words today. The character you already know is 猴.

> **A:** 这是猴怪吗？ Zhè shì Hóuguài ma? — Is this Mankey?
>
> **B:** 不是。这是火暴猴。 Bú shì. Zhè shì Huǒbàohóu. — No. This is Primeape.

## Homework

Choose three animal or Pokemon pictures.

1. Write a sentence identifying each picture, using 这是 or 那是. Add pinyin.
2. For one picture, write a yes/no question with 吗 and answer it.
3. Record yourself asking 这是什么？ and answering with one of your sentences.

Before moving on, try to ask what something is, name it, and correct a wrong guess without reading the examples.
